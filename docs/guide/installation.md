# 安装与首次配置

本页适合第一次部署 MatrixClass 的管理员。建议先在两台测试设备上完成一次完整流程，再批量部署到机房。

## 准备清单

- 教师端和学生端使用同一版本，避免协议字段或媒体编码不一致。
- 两端处于可以互相访问的局域网，网络配置文件不要启用客户端隔离。
- 为教师端预留一个固定的运行目录；教师端的 SQLite 数据库会放在程序同目录。
- 确定一个数字频道 ID，例如 `1`、`12` 或 `202601`。同一课堂的学生端必须使用相同频道。
- 在防火墙中允许程序使用专用网络，并确认 KCP 使用的 UDP 流量没有被拦截。

## Windows 安装

1. 运行教师端或学生端 NSIS 安装程序。
2. 保持默认安装选项，安装完成后学生端会自动启动。
3. 教师端首次启动设置账号密码并选择数字频道。
4. 学生端首次启动设置退出密码和数字频道。
5. 两端连接成功后，再将学生端安装包分发到其他设备。

详细步骤见 [Windows 安装](/deploy/windows)。

## Linux 与 macOS

Linux 的教师端和学生端是两个独立安装包：教师机安装 `matrixclass-teacher`，学生机安装 `matrixclass-student`。统信 UOS / Deepin / 麒麟 / Ubuntu 选 `.deb`，openEuler / 龙蜥 / CentOS 选 `.rpm`，其他发行版使用 tar.gz 目录包。学生端安装后立即启动，并在每次登录桌面时自动启动，卸载需要退出密码。详细步骤见 [Linux 安装](/deploy/linux)。

macOS 使用 Universal `dmg`（同时包含教师端和学生端），也可以选择 Intel 或 Apple Silicon 的 zip 包，详见 [macOS 安装](/deploy/macos)。

首次运行时需要给屏幕采集、输入控制和麦克风功能授予系统权限；没有权限时，控制消息仍可能正常连接，但采集类功能会不可用。

## 首次验证

按下面顺序验证，比直接测试全部功能更容易定位问题：

1. 教师端底部显示正确频道并处于“就绪”。
2. 学生端状态从连接中变为已连接。
3. 教师端设备视图出现学生机位。
4. 发送一条课堂消息，确认学生端右下角出现通知。
5. 发送一个小文件，确认学生端下载队列出现进度。
6. 开启屏幕监控，确认能看到学生端画面。

## 安装目录建议

不要把程序放在临时目录、压缩包内部或只读目录。教师端数据库和运行日志需要可写权限；学生端的接收文件、配置和退出密码数据也需要稳定的本地目录。

::: warning
不要把教师端数据库、学生端配置文件和退出密码文件上传到公共网盘或提交到 Git 仓库。
:::
