# 一堂课的完整流程

下面是一套适合日常课堂的标准流程。各功能也可以单独使用，不需要严格按顺序操作。

## 课前：确认设备

1. 打开教师端，选择数字频道并登录。
2. 在设备视图确认学生端在线数量。
3. 使用搜索框筛选机位、学号或 IP，处理离线设备。
4. 需要批量操作时使用 `Ctrl+A`、`Ctrl+鼠标左键` 或拖动框选。

## 开始：签到与通知

点击“点名签到”后，学生端才会弹出签到窗口。学生填写班级和姓名并提交，教师端可以查看签到状态。课堂消息用于发布迟到提醒、实验要求或下课通知，学生端右下角会弹出提示。

## 讲解：广播或网络影院

- “屏幕广播”适合演示桌面操作。
- “网络影院”适合播放教师端的视频流，教师端可以控制播放进度和暂停状态。
- “学生演示”适合批准某个学生共享屏幕。
- “屏幕监控”适合巡检，不等同于向全班广播。

## 实验：文件与远程操作

教师可以将实验资料分发到学生桌面，也可以收取学生作业。远程操作页面支持从控制面板程序列表选择应用，也可以输入路径或执行 CMD、PowerShell 命令。涉及命令执行时，只对明确授权的教学设备使用。

## 下课：结束任务

1. 停止屏幕广播、语音广播或网络影院。
2. 结束作业收取，确认学生端提交窗口关闭。
3. 检查文件分发队列中是否存在失败项目。
4. 需要时导出或备份作业目录与教师端数据库。

## 课堂状态判断

| 状态 | 说明 | 建议动作 |
| --- | --- | --- |
| 在线 | 学生端保持连接 | 可以执行课堂操作 |
| 离线 | 暂时没有心跳 | 等待重连或检查网络 |
| 已签到 | 学生已提交签到 | 继续课堂流程 |
| 无画面 | 连接存在但媒体未恢复 | 等待关键帧或检查采集权限 |
| 传输失败 | 文件未完整到达 | 在队列中重试 |
