# 故障排查清单

遇到问题时先确认影响范围：是所有学生端异常，还是单台设备异常；是控制消息异常，还是屏幕、音频或文件传输异常。

## 学生端完全不出现

1. 确认教师端和学生端的数字频道完全一致。
2. 确认两台设备在同一可达网段，关闭会隔离客户端的无线 AP 设置。
3. 临时允许程序通过 Windows 专用网络防火墙。
4. 检查学生端是否已经在托盘运行，避免重复启动多个实例。
5. 查看日志中是否出现端口被占用或权限拒绝。

## 学生端反复重连

教师端关闭、网络切换或 KCP 会话中断时，学生端会显示掉线提示并持续重试。若超过预期时间仍未恢复，检查频道、网卡、UDP 防火墙和局域网隔离；不要先删除学生端配置，否则会失去原有频道设置。

## 屏幕监控没有画面

- 确认设备卡片仍显示在线。
- 检查学生端是否拥有桌面采集权限。
- 检查目标设备是否锁定、切换用户或进入远程桌面会话。
- 降低教师端监控帧率和画质后重新观察。
- 如果只有一台设备异常，优先处理该设备的采集权限；如果全部异常，优先检查教师端网络和协议状态。

## 文件传输卡住

查看教师端和学生端的队列状态。传输支持断点续传、覆盖重传和失败重试；不要在任务仍显示传输中时重复点击发送，以免产生重复队列。接收路径为空时，学生端默认保存到桌面。

## macOS 打不开

未签名应用可能被 Gatekeeper 拦截。先在“系统设置 → 隐私与安全性”中允许打开，再按系统提示授予屏幕录制、辅助功能和麦克风权限。Universal 包包含 Intel 和 Apple Silicon 两种架构，但不等于已经完成 Apple 开发者签名与公证。
