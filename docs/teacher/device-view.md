# 设备视图与监控

设备视图是教师端的默认工作区。每张设备卡片展示机位编号、设备编号、连接状态、签到状态、IP 地址和延迟。

![设备视图真实截图](/screenshots/teacher-device-view.png)

设备视图和屏幕监控支持快捷多选：

- `Ctrl+A`：全选当前视图设备。
- `Ctrl+鼠标左键`：切换单个设备选择状态。
- 长按拖动：框选多个设备。
- 点击空白处：清除选择。
- 右键空白处：清理离线电脑。

设备视图底部是分组导航栏。默认分组始终存在，可以通过 `+` 创建其他分组；分组只影响教师端的组织方式，不会修改学生端配置。

监控画质和帧率在教师端设置中调整。学生端断线后会持续重连，教师端会在恢复后请求关键帧并重启监控流。

## 屏幕监控

![屏幕监控视图](/screenshots/teacher-monitor.png)

切换顶部“屏幕监控”选项卡后，教师端以缩略图显示学生屏幕。监控过程中可以继续使用快捷选择和批量操作；画质、帧率和重连策略在“设置”中调整。若单台设备暂时没有画面，先观察卡片状态是否仍在线，恢复连接后教师端会自动请求新的关键帧。

## 设备卡片字段

| 字段 | 含义 |
| --- | --- |
| 机位编号 | 教师端显示的设备位置，例如 `PC-01`，用于快速定位座位 |
| 设备编号 | 学生端上报的课堂设备标识，不等同于 Windows 计算机名 |
| 在线/离线 | 最近心跳和控制会话状态；在线不代表屏幕采集权限一定可用 |
| 已签到/未签到 | 本次点名签到的提交状态，重新开始签到后按新一轮状态计算 |
| IP 与延迟 | 当前连接地址和最近一次往返延迟，用于判断局域网质量 |
| 举手/锁屏 | 学生端主动举手或教师端下发锁屏策略后的状态提示 |

## 选择与批量操作

设备视图和屏幕监控使用相同的选择规则。先选择设备，再点击工具栏动作；没有选中设备时，教师端会提示选择目标，避免误操作整间教室。

1. 使用 `Ctrl+A` 选择当前分组内全部设备。
2. 按住 `Ctrl` 单击设备卡片，可以加入或移除单台设备。
3. 在空白区域按住鼠标左键拖动，框选一批设备。
4. 点击空白处清除全部选择。
5. 对选中设备右键，打开批量操作菜单。

## 分组管理

底部横向导航栏包含“默认分组”和自定义分组。新建分组后可以将设备移动到对应分组；分组只保存在教师端，不会改变学生端连接频道。上课前可以按座位区域建立“前排”“后排”或“演示组”，下课后仍可复用。

## 监控无画面的判断顺序

1. 看设备卡片是否仍在线。
2. 看教师端底部丢包率是否突然升高。
3. 只对异常设备执行重新监控，避免全班同时请求关键帧。
4. 检查学生端桌面采集权限、锁屏状态和远程桌面会话。
5. 如果全部设备都无画面，检查教师端设置中的画质、帧率和网卡选择。
