# 文件与作业

## 文件分发

![文件分发窗口](/screenshots/teacher-file-distribute.png)

点击“文件分发”会打开独立窗口。文件分发窗口支持拖动或手动添加文件，也支持文件夹；可以在发送前设置接收路径，未设置时默认发送到学生机桌面。

操作步骤：

1. 将文件或文件夹拖入上传队列，或点击“添加文件”。
2. 检查队列中的目标路径和覆盖选项。
3. 点击“发送”，观察每台学生机的进度条。
4. 失败项目可以点击“重试”；断点传输会从已完成位置继续。

学生端会打开独立的下载队列窗口，显示文件名、来源、进度和重试按钮。文件默认不会自动打开。

传输层支持断点续传、覆盖重传和丢包恢复。

## 文件分发窗口字段

| 字段 | 用途 |
| --- | --- |
| 上传队列 | 显示待发送文件和文件夹，可以继续拖入项目 |
| 接收路径 | 为空时使用学生机桌面；设置后按学生端权限写入目标目录 |
| 覆盖 | 同名文件存在时自动覆盖，不需要先手动删除旧文件 |
| 进度 | 显示每个学生端的已发送字节数和总大小 |
| 重试 | 仅重新发送失败或中断的项目，已完成部分继续使用断点 |

## 分发大文件和文件夹

文件夹会保留相对目录结构。发送前检查文件夹中是否包含临时文件、缓存目录或不应下发的隐私文件；需要取消时先停止队列，再删除未发送项目。大量设备同时接收时，建议分组分批发送，并观察教师端底部的发送速率和丢包率。

## 作业收取的完整流程

1. 在设备视图选择收作业范围，未选择时按当前课堂范围处理。
2. 点击“收取作业”，选择本次作业保存目录。
3. 如果取消目录选择，系统使用设置中的作业目录，默认是系统 `Downloads`。
4. 教师端发布任务后，学生端自动弹出提交文件页面。
5. 学生拖入文件或点击添加，确认后点击“提交”。
6. 教师端查看学生、文件名、大小、进度和保存结果。
7. 确认需要补交的学生处理完毕后，点击结束收取。

学生端提交窗口只有在教师端结束收取后才会关闭；教师端不要在学生上传过程中直接退出程序。

## 常见失败状态

- **等待连接**：学生端暂时离线，恢复后会继续任务。
- **传输中断**：网络或进程暂时不可用，点击重试即可从断点继续。
- **路径不可写**：学生端没有目标目录权限，改用桌面或用户目录。
- **同名覆盖失败**：目标文件被其他程序占用，关闭占用程序后重试。

## 作业收取

![作业与文件记录](/screenshots/teacher-files.png)

![学生端作业提交窗口](/screenshots/student-homework.png)

点击“收取作业”时先选择保存目录；取消选择时使用设置中的作业目录，默认是系统 `Downloads`。开始收取后，学生端会弹出独立提交页面，学生可以拖动文件或手动添加后点击提交。教师端结束收取前，学生端提交窗口不会自动关闭。

教师端可以在队列中查看学生、文件名、传输进度和保存结果。作业收取结束后再关闭窗口，避免学生提交到一半被中断。
