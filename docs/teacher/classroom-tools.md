# 消息、签到与测验

## 课堂消息

教师端输入消息后点击“发送”。学生端右下角弹出通知，点击后打开独立消息页面。消息页面可以单独关闭，不会结束课堂连接。

## 点名签到

![学生端签到窗口](/screenshots/student-checkin.png)

学生端没有主动点名按钮。教师端发起签到后，学生端自动弹出签到页面，学生分别输入班级和姓名并提交。教师端设备视图显示已签到或未签到状态。

## 随堂测验

![教师端随堂测验](/screenshots/teacher-exam.png)

![学生端测验窗口](/screenshots/student-exam.png)

随堂测验由教师端创建并发布。学生端平时隐藏测验入口，只有收到教师端发布的测验后才弹出新的测验窗口。结束测验后教师端可以查看提交状态。

## 举手

学生端通过悬浮条发起举手，教师端在举手队列中批准演示或忽略。消息、举手和签到状态都可以在设备视图中快速查看。

## 批量操作

在设备视图或屏幕监控页面按 `Ctrl+A` 全选，按住 `Ctrl` 单击可以切换单台设备；点击空白处取消选择，长按拖动可以框选。右键选中设备可以执行批量课堂操作。
