# 远程操作

远程操作页面采用双栏布局：左侧选择启动程序或执行命令，右侧显示当前操作内容。

- 程序列表来自学生端控制面板程序列表。
- 也可以输入绝对路径启动指定软件。
- 支持执行 CMD 和 PowerShell 命令。
- 学生端会返回启动或执行结果，教师端显示任务状态。

## 启动程序

![远程启动程序](/screenshots/teacher-remote-exec.png)

左侧选择“启动程序”后，教师端加载学生端控制面板程序列表。列表用于筛选已安装的常用程序，不是把学生端所有可执行文件全部扫描出来。

1. 选择目标学生设备。
2. 在左侧选择启动程序。
3. 从控制面板程序列表中选择应用，或切换到路径输入。
4. 使用右侧启动面板确认应用名称、路径和目标设备。
5. 点击执行并等待学生端返回结果。

如果程序需要管理员权限、用户交互或图形桌面，学生端可能只能返回启动请求已发送，不能保证应用窗口一定可见。

## 执行命令

![远程执行命令](/screenshots/teacher-remote-command.png)

左侧切换到“执行命令”后，右侧显示命令编辑器和执行结果。分别选择 CMD 或 PowerShell，输入命令并确认目标设备，再点击执行。

建议先使用只读命令验证环境，例如查看当前目录、系统版本或网络配置；需要修改系统的命令应在课堂前单机验证。

| 类型 | 适合场景 | 注意事项 |
| --- | --- | --- |
| CMD | 兼容旧版批处理和简单程序调用 | 路径含空格时需要正确引用 |
| PowerShell | 查询系统、批量配置和脚本化操作 | 脚本执行策略和权限可能阻止命令 |

## 任务结果

教师端应显示任务已发送、执行中、成功或失败。失败时先检查学生端是否在线，再查看返回的错误文本；不要在没有确认前连续发送同一个命令。

## 安全边界

远程操作可以影响学生机上的程序和文件，只对获得管理授权的设备使用。不要把密码、令牌、个人文件路径或破坏性命令写入课堂消息、截图或日志；批量执行前先选择一台测试设备。

::: warning
远程命令具有较高权限风险，应只在获得管理授权的课堂设备上使用。
:::
