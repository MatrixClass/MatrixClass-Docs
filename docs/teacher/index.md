# 教师端

教师端是课堂的控制中心，启动时选择数字频道并登录教师账号。界面采用设备视图作为主工作区，将常用课堂动作放在顶部工具栏，底部保留连接状态、频道和音量控制。

截图来自真实运行中的教师端窗口，展示设备卡片、分组导航、消息与举手区域以及扬声器/麦克风控制。

## 建议的工作顺序

1. 启动后选择频道 ID，确认状态栏显示“就绪”。
2. 在设备视图检查在线设备，必要时使用搜索框筛选机位、学号或 IP。
3. 使用 `Ctrl+A` 全选，按住 `Ctrl` 单击切换单台设备，点击空白处清除选择。
4. 需要批量操作时在设备卡片或空白处右键打开菜单。
5. 课堂结束前停止广播、结束作业收取，并确认未完成的传输已处理。

## 主要入口

- 设备视图：查看在线设备、分组和连接状态。
- 屏幕监控：查看学生屏幕并批量控制监控流。
- 文件分发：将文件或文件夹发送到学生桌面或指定路径。
- 作业收取：选择保存目录，等待学生提交并查看结果。
- 远程操作：启动学生端程序或执行命令。
- 管控策略：编排、下发和撤销课堂规则。

## 音频控制

右下角分别提供扬声器和麦克风音量滑块。点击对应“静音”按钮可以单独静音；音量设置只影响当前教师端会话，不改变系统全局音量。
