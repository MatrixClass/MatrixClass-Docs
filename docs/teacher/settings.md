# 频道、账号与设置

## 启动选择

![频道与账号登录](/screenshots/teacher-channel-login.png)

教师端每次启动都需要确认数字频道 ID，并完成教师账号验证。频道 ID 使用数字下拉框选择，不输入教师姓名或机房名称。

首次运行时默认用户名为 `admin`，密码为空；首次保存后应立即设置非空密码。忘记密码时不要直接删除数据库，先使用项目提供的管理员恢复流程。

## 持久化数据

![教师端设置](/screenshots/teacher-settings.png)

教师端使用 SQLite 保存账号、频道、分组、课堂状态和部分设置，数据库文件放在教师端程序同目录。备份时应先退出教师端，再复制数据库文件，避免复制到未完成写入的状态。

## 屏幕监控

![屏幕监控设置](/screenshots/teacher-settings-monitor.png)

监控画质和帧率位于教师端设置页面。高画质、高帧率会明显增加局域网带宽和学生端解码压力，建议机房环境先从中等画质和适中帧率开始。

## 音频

右下角分别提供扬声器和麦克风滑块，并可以单独静音。扬声器控制教师端播放音量，麦克风控制教师端采集音量；两者不是同一个开关。

## 窗口行为

![网络与教师指纹设置](/screenshots/teacher-settings-network.png)

教师端默认以适中的窗口大小打开，可以手动最大化。由教师端发起的签到、测验、文件分发和作业窗口会独立显示，避免主工作区被覆盖。
