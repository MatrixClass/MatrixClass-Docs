# 管控策略

管控策略入口位于教师端导航栏，点击后以独立弹窗编排并下发课堂规则。当前采用单条策略模式，便于在小窗口中阅读和操作。

## 使用流程

![管控策略弹窗](/screenshots/teacher-policy.png)

1. 在设备视图选择目标学生机。
2. 打开“管控策略”。
3. 选择要下发的课堂规则并确认范围。
4. 点击下发，观察设备状态变化。
5. 需要恢复时点击撤销策略。

## 注意事项

- 只对明确授权的教学设备使用管控功能。
- 发送前确认设备选择范围，避免误操作整组学生机。
- 网络断开时不要连续重复下发，恢复连接后再查看状态。
- 策略撤销是教师端的恢复入口，结束课堂前应确认已撤销不再需要的规则。
