# 广播、影院与演示

## 屏幕广播

屏幕广播将教师端当前桌面发送到学生端。开始前可以选择窗口模式广播或整个桌面广播；结束时再次点击工具栏按钮停止。广播卡顿时，先降低设置中的帧率和画质，再检查丢包率。

## 语音广播

语音广播使用教师端麦克风向学生端传输课堂语音。开始前确认麦克风没有被系统静音；右下角滑块可以调整采集音量。

## 网络影院

![网络影院](/screenshots/teacher-theatre.png)

网络影院传输的是教师端的视频流，不是先把视频文件分发到学生机。教师端可以播放、暂停和调整进度；学生端保持视频窗口打开，暂停时不会退出影院页面。

## 学生演示

学生举手后会出现在教师端的举手队列。教师点击“批准演示”后，学生端才会开始演示。演示结束后可以撤销批准或切换回教师广播。

## 典型问题

| 现象 | 处理 |
| --- | --- |
| 学生看到旧画面 | 停止后重新开始广播，等待新关键帧 |
| 画面卡顿 | 降低帧率、画质，减少同时监控设备数量 |
| 影院显示成广播 | 确认使用“网络影院”入口，而不是屏幕广播入口 |
| 学生端没有窗口 | 确认学生端在线，并检查独立窗口是否被系统最小化 |
