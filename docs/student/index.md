# 学生端

学生端默认安静运行，只有教师发起签到、测验、消息、文件接收或作业提交时才弹出对应窗口。

![学生端课堂悬浮条](/screenshots/student-bar.png)

上图为真实运行中的学生端界面。学生端平时以悬浮条和托盘状态保持连接，不占用课堂主屏；教师发起课堂操作后，相关窗口会自动置顶显示。

- 安装完成后自动启动。
- 首次启动必须设置退出密码和数字频道 ID。
- 断线后持续自动重连并显示连接状态。
- 托盘参数设置需要退出密码验证。
- 退出和卸载学生端需要密码验证。

## 黑屏锁屏

教师端下发黑屏锁屏后，学生端全屏显示锁定提示。左下角可举手；连续点击锁屏文字 5 次会出现密码框，输入首次安装时设置的学生端密码即可紧急解锁。
