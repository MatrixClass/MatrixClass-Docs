# 首次启动与频道

首次启动窗口用于完成学生端的安全配置和频道配置。退出密码不是教师端密码，教师端只能在需要时远程重置学生端密码。

![学生端首次启动设置](/screenshots/student-first-run.png)

完成首次配置并连接教师端后，学生端会进入轻量运行状态。截图中的悬浮条显示当前课堂连接和常用入口；首次配置窗口只在首次启动或配置尚未完成时出现。

首次启动窗口设置：

1. 学生端退出密码。
2. 连接教师端的纯数字频道 ID。

## 字段说明

| 字段 | 填写要求 |
| --- | --- |
| 设置退出密码 | 输入学生端退出、参数设置和卸载验证使用的密码 |
| 再次输入退出密码 | 必须与第一次输入完全一致，用于避免误输入 |
| 频道 ID | 选择或输入教师端使用的纯数字频道，例如 `1` |

退出密码不需要与教师端账号密码相同。不要使用容易被同一教室学生猜到的班级编号作为退出密码。

配置完成后学生端自动开始搜索频道。右键托盘图标选择“参数设置”，输入退出密码后可以修改频道；保存后会关闭旧连接并自动重连新频道。

## 配置完成的标志

- 首次启动窗口关闭。
- 学生端悬浮条显示当前频道或连接状态。
- 教师端设备视图出现对应设备卡片。
- 教师端发送消息后，学生端可以弹出通知。

如果配置保存后没有加入课堂，先核对频道 ID，再按[防火墙与多网卡](/deploy/firewall)检查网络。

## 连接异常

如果教师端暂时关闭、网络切换或 KCP 会话中断，学生端会保留当前配置并显示连接掉线提示，然后持续重连。恢复后无需再次输入密码或频道 ID。
