# 课堂消息与通知

学生端消息页面由教师端发起，不需要学生端提前打开。收到消息后，学生端会显示右下角提示，并将消息窗口置顶。

![学生端消息提示](/screenshots/student-toast.png)

## 阅读消息

![课堂消息窗口](/screenshots/student-chat.png)

点击通知或悬浮条中的“消息”进入独立页面。关闭消息页面不会断开学生端连接，也不会影响正在进行的文件接收或作业提交。

## 消息没有出现

确认学生端仍显示在线，检查系统通知是否被勿扰模式隐藏，并确认教师端发送目标包含当前设备。消息发送失败时先观察教师端连接状态，不要连续点击发送。

## 与其他课堂窗口的关系

消息、签到、测验、文件接收和作业提交是独立窗口。教师端发起哪个功能，学生端才显示哪个页面；学生端不会出现教师端未发布的随堂测验或点名按钮。
