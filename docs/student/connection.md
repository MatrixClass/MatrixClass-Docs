# 断线重连与托盘

## 自动重连

![断线重连提示](/screenshots/student-reconnect.png)

学生端保存频道配置和退出密码。教师端关闭、网卡切换、无线网络短暂中断或 KCP 会话断开时，学生端会单独显示“连接掉线，正在重新连接”，并持续尝试加入原频道。

恢复连接后不需要再次输入频道 ID，也不需要重新安装学生端。教师端恢复监控时会请求新的关键帧。

## 托盘菜单

学生端正常运行时主要停留在托盘。右键托盘图标可以打开参数设置、查看连接状态或退出。进入参数设置和退出学生端都需要验证退出密码；教师端可以远程重置该密码。

## 更换频道

![参数设置密码验证](/screenshots/student-password.png)

![学生端参数设置](/screenshots/student-settings.png)

1. 右键托盘图标选择“参数设置”。
2. 输入退出密码。
3. 选择新的数字频道 ID。
4. 保存后学生端关闭旧会话并自动连接新频道。

## 断线时不要做什么

- 不要反复启动多个学生端进程。
- 不要删除配置文件来“修复”重连。
- 不要在教师端连续发送大量文件，先等待连接状态稳定。
