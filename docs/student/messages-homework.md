# 消息与作业

教师端发送消息时，学生端右下角弹出提示；课堂消息和作业提交是两个独立页面。

![学生端课堂入口](/screenshots/student-bar.png)

学生端收到教师端指令后，会从悬浮条或右下角提示进入对应的独立窗口。消息、文件下载和作业提交互相独立，关闭其中一个不会影响其他任务。

## 课堂消息

![课堂消息窗口](/screenshots/student-chat.png)

消息窗口由教师端发起，学生端收到后自动置顶显示。阅读后可以关闭窗口，不会影响学生端后台连接。学生端不会显示教师端未发起的课堂功能入口。

消息窗口通常包含发送时间、教师端来源和消息正文。消息提示被关闭后，仍可以通过悬浮条进入当前课堂消息页面；如果教师端发送新消息，学生端会再次提示。

教师发起收取作业后，学生端弹出提交窗口，可以拖动文件或点击添加，点击提交后显示传输进度。教师结束收取前，学生端提交窗口不会自动关闭。

## 作业提交步骤

![作业提交窗口](/screenshots/student-homework.png)

1. 等待教师端发起收取作业，不要从学生端主动打开作业入口。
2. 在提交窗口拖入文件，或点击“添加文件”选择文件。
3. 检查队列中的文件名、大小和数量。
4. 点击“提交”，等待每个文件完成。
5. 如果某个文件失败，点击该项的重试按钮；不要重复添加同一个文件。
6. 保持窗口打开，直到教师端结束收取。

作业提交支持多个文件。若教师端要求目录结构，使用文件夹内的相对路径整理文件后再提交。

## 文件接收

![文件接收队列](/screenshots/student-file-receive.png)

教师端下发文件时，学生端会打开独立下载窗口。窗口显示队列、当前文件、进度和重试按钮；默认保存到桌面且不会自动打开。教师端关闭分发任务后，窗口才会结束本次队列。

下载窗口中的“重试”只针对失败项目；已完成文件不会重复下载。收到文件后可以从桌面或教师端指定目录打开，MatrixClass 默认不会自动打开文件。
