# 常见问题

## MatrixClass 和传统单网卡教室软件有什么不同？

传统软件通常只监听一块网卡，装了虚拟机或组网工具后容易绑错网卡而断联。MatrixClass 默认多网卡模式，在所有局域网网卡上发现教师端，并自动忽略虚拟机网卡和隧道类虚拟网卡；网卡切换后学生端会刷新网卡列表并持续重连。无线隔离和组播限制仍可能导致发现异常，具体排查请看[防火墙与多网卡](/deploy/firewall)。

## 频道 ID 应该怎么设置？

使用数字下拉框选择，不要输入班级名称或教师姓名。同一课堂的教师端和学生端必须选择相同数字；不同教室建议使用不同数字，避免误加入。

## 学生端为什么没有签到和测验按钮？

这是预期行为。签到和测验由教师端发起，学生端收到指令后才弹出独立窗口，避免学生端自行发起课堂流程。

## 学生端显示正在重连

检查教师端和学生端是否选择了相同数字频道，确认两台设备处于同一可达局域网，并允许防火墙中的专用网络访问。学生端会持续重试，不需要手动重启。

## 屏幕监控一段时间后无画面

优先确认学生端仍在线，再检查桌面采集权限和网络丢包。教师端会在解码错误或连接恢复后请求关键帧并重启监控流。

## 文件分发卡住

查看学生端下载队列中的进度和重试按钮。文件传输支持断点续传和覆盖重传；学生端恢复连接后可以再次重试。

## Linux CI 为什么不测试真实屏幕和音频

GitHub Actions 的 Linux Runner 通常没有桌面会话、音频设备或 PipeWire/PulseAudio。CI 会跳过硬件依赖部分，但继续测试编码、协议、传输和业务逻辑。

## macOS 的 Universal 是什么？

Universal 包同时包含 Intel 和 Apple Silicon 架构代码，不代表已经完成 Apple 开发者签名、公证或所有系统权限配置。未签名 DMG 首次打开时需要手动允许。

## 教师端数据库放在哪里？

SQLite 数据库放在教师端程序同目录。备份或迁移前先退出教师端，复制数据库和相关配置；不要在程序运行时直接覆盖数据库。

## 可以把教师端端口暴露到公网吗？

不建议。MatrixClass 面向受控局域网课堂，频道 ID 不是公网安全边界。需要远程授课时应使用经过审批的 VPN 或专用网络，并额外限制防火墙来源。

## 为什么发送按钮点击多次后文件会集中发出？

教师端会把文件加入发送队列，网络恢复或连接重新建立后，队列中的任务可能连续发送。遇到发送延迟时不要反复点击“发送”；先查看队列和学生端在线状态，必要时停止重复任务，再重试失败项。

## 学生端窗口为什么不能关闭？

由教师端发起的签到、测验、文件接收和作业提交窗口可能被设计为置顶或在教师端结束任务前保持打开。这样可以避免学生误关窗口导致任务状态丢失；教师结束对应课堂任务后，窗口才会正常关闭。

## 文件默认保存在哪里？

教师端分发文件默认保存到学生机桌面，且不会自动打开。教师端可以在文件分发窗口中设置接收路径。作业收取默认保存到教师端设置中的作业目录，未设置时使用系统 `Downloads`。

## 为什么控制消息正常但屏幕没有画面？

控制消息和屏幕媒体使用不同的数据与权限路径。先确认学生端在线，再检查学生端桌面采集权限、锁屏状态、远程桌面会话、教师端监控画质和帧率。Linux 和 macOS 还需要检查系统隐私权限。

## 删除离线设备会删除学生端吗？

不会。设备视图右键空白处清理的是教师端列表中的离线记录，不会卸载、删除或修改学生端程序和配置。学生端重新连接后会作为新状态重新出现。
