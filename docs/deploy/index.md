# 部署与网络

MatrixClass 支持 Windows amd64/arm64、Linux amd64/arm64/loong64 和 macOS amd64/arm64。部署重点不是“能否启动”，而是让教师端、学生端、桌面采集和文件目录在真实课堂网络中稳定工作。

## 推荐部署顺序

1. 先在教师机安装教师端，选择一个数字频道并完成账号设置。
2. 在一台学生机安装学生端，设置退出密码和相同频道。
3. 验证消息、文件、屏幕监控和重连，再批量安装。
4. 将学生端安装包分发到同一课堂的设备，不要复制运行中的配置文件。
