# 频道与 KCP

频道 ID 是纯数字逻辑频道。学生端通过 UDP 广播/组播发现教师端，再使用 KCP 建立会话；默认在所有局域网网卡上同时发现并自动忽略虚拟网卡，网络切换后学生端会刷新网卡列表并持续尝试重连。

如果组播不可用，媒体数据会使用 KCP 回退路径。仍需保证教师端和学生端存在一条可达的局域网路径。

## 频道如何工作

频道 ID 用于把同一局域网内的课堂分开。教师端启动时选择频道，学生端启动时选择要加入的频道；频道不等于密码，也不替代教师账号认证。

## 连接阶段

| 阶段 | 现象 | 说明 |
| --- | --- | --- |
| 发现 | 学生端搜索频道 | 使用 UDP 广播/组播或可达接口 |
| 建连 | 显示连接中 | 建立 KCP 会话并交换设备状态 |
| 就绪 | 教师端出现设备卡片 | 可以发送消息、文件和控制操作 |
| 重连 | 学生端显示掉线提示 | 保留配置并持续尝试加入原频道 |

## 带宽建议

控制消息占用很小，屏幕广播、屏幕监控和网络影院是主要带宽来源。设备数量较多时，优先降低画质和帧率，避免在同一时间对全部设备开启高质量监控。

## 频道规划示例

可以按教室或课程规划数字频道，避免多个教师端使用同一个频道：

| 教室 | 频道示例 | 说明 |
| --- | ---: | --- |
| 一号机房 | `101` | 教师端和该机房学生端统一使用 |
| 二号机房 | `102` | 与一号机房隔离课堂设备列表 |
| 移动实验组 | `201` | 临时设备使用独立频道 |

频道只是逻辑分组。即使频道不同，两端仍需要处于可达网络；频道相同也不代表跨网段、防火墙阻断的设备一定能连接。

## 网络变化后的处理

学生端检测到网卡地址或默认路由变化时，会关闭旧会话并重新发现频道。教师端设备卡片可能短暂变为离线，恢复后应等待新的心跳和关键帧，不要立即删除设备或重新安装程序。
