# 防火墙与多网卡

## 防火墙

教师端和学生端需要在局域网内互相发现并建立 UDP/KCP 会话。首次运行时允许程序访问专用网络；如果系统询问公用网络权限，应根据学校网络策略决定，不要无条件开放到互联网。

排查顺序：

1. 确认两端 IP 地址位于可互通网段。
2. 临时关闭客户端隔离或无线 AP 的访客隔离。
3. 在防火墙中允许教师端和学生端程序。
4. 检查安全软件是否拦截未知 UDP 流量。
5. 用最小化测试验证消息，再测试屏幕和文件。

## 多网卡

传统电子教室软件通常只监听一块网卡，电脑装了虚拟机、加速器或组网工具后，很容易绑到错误的网卡上导致断联。MatrixClass 默认使用**多网卡模式**，会同时在所有可用的局域网网卡上发现教师端，并**自动忽略虚拟网卡**，无需手动关闭这些网卡。

### 自动忽略的虚拟网卡

多网卡模式下默认开启两项过滤，按网卡名称识别：

| 选项 | 默认 | 会被忽略的网卡 |
| --- | --- | --- |
| 忽略虚拟机网卡 | 开启 | VMware、VirtualBox、Hyper-V（vEthernet）、Docker、Podman、Linux 网桥（`br-`、`virbr`）等 |
| 忽略虚拟网卡（隧道类） | 开启 | TUN / TAP、PPP、WireGuard、ZeroTier、Tailscale 等组网工具创建的网卡 |

被忽略的网卡不会参与课堂发现，物理有线网卡和无线网卡不受影响。

### 两种网卡模式

| 模式 | 适用场景 | 说明 |
| --- | --- | --- |
| 多网卡（自动） | 绝大多数机房，推荐 | 在所有未被忽略的网卡上发现教师端，网卡切换后自动重连 |
| 单网卡（手动选择） | 机器有多块物理网卡，需要固定走某一块 | 只在选定的网卡上监听，其他网卡全部忽略 |

### 在哪里设置

- **单台学生机**：右键托盘图标 → 参数设置，输入学生端退出密码后进入，选择网卡模式并勾选忽略选项。
- **批量设置**：在教师端设备视图选中多台学生机，打开网卡设置后统一下发，学生端保存后自动重连。

![学生端参数设置](/screenshots/student-settings.png)

::: tip
如果某台机器的虚拟网卡名称比较特殊、没有被自动识别，改用“单网卡（手动选择）”并选定教室网卡即可。不要只根据“能上网”判断课堂网络可达。
:::

## 单网卡监听问题

MatrixClass 不依赖单一网卡：多网卡模式会在网卡地址或默认路由变化时刷新网卡列表，关闭旧会话并重新发现教师端；虚拟网卡被自动排除，不会抢走课堂连接。组播受限或无线隔离仍可能造成发现异常，出现间歇性断联时，记录网卡、IP、频道和丢包率，再按本页排查。

## 安全边界

频道 ID 只用于课堂分组，不是安全认证。教师端账号、学生端退出密码和局域网防火墙共同构成管理边界，不要把教师端端口直接暴露到公网。
